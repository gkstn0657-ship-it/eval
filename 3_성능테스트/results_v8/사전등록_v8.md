## 문제 분석 방법론 (후보와 선택)

| 후보 | 내용 | 판정 |
|---|---|---|
| 1. 실패 문항 오류 분류 + 단계별 손실 귀속 | 완전 정답(1.0)이 아닌 14문항의 상위 5개와 정답 조문을 대조해 실패 유형을 묶고, 각 유형이 파이프라인 어느 단계(후보 생성·필터·재랭킹)에서 생기는지 특정 | **채택.** 추가 실행 없이 기존 per_query 로 가능, 유형별로 수정안이 바로 나옴 |
| 2. 오라클 상한 | 풀 안 재랭킹이 완벽했을 때 nDCG 상한 | 보조. 후보 생성 vs 재랭킹 어느 쪽이 병목인지 확인용 |
| 3. 구성요소 제거 | 필터·BM25·재랭커 유무 | 이미 수행(v4~v6). 남은 실패를 특정하지 못함 |
| 4. 질의-문서 토큰 중첩 검사 | 왜 엉뚱한 조문이 올라오는지 기전 확인 | 1의 하위 도구로 사용 |
| 5. 유형 층화 | 유형별 Recall | 이미 수행 |

## 분석 결과 (방법론 1 적용, L2P_A hybrid, 1.0 미만 14문항)

| 유형 | 문항 | 기전 | 단계 |
|---|---|---|---|
| A. 제1조(목적)·제2조(정의)가 정답 위에 옴 | Q1-01, Q1-03, Q4-06, Q10-01, Q11-01, Q11-03, Q11-06, Q11-08 (8) | 질의의 기관명 토큰이 제1조 본문("이 규정은 한국토지주택공사 직원에게…")과 매칭. 제1조 36개 중 18개가 기관명 포함. 기관은 이미 필터가 처리하므로 점수 계산에서 기관명은 잡음 | 후보 생성(BM25·dense)과 재랭킹(CE) 모두 |

| C. 정답이 풀 밖 | Q5-05 (정의 조항), Q8-08 (부칙 별표) (2) | Q8-08 은 부칙 표가 L2 에서 분리돼 코퍼스에 없음. Q5-05 는 호 단위 분할 뒤에도 "전직·전보" 정의 조각이 후보에 안 올라옴 | 후보 생성·코퍼스 |

## 수정안과 예상

- 수정 1 (유형 A): 질의에서 기관 별칭을 제거한 문자열로 dense·BM25·CE 점수 계산. 필터는 원래 질의에서 감지한 기관으로 그대로. `hybrid_qstrip`.
  - 예상: A 8문항이 1.0 이 되면 +0.09 → 0.89. 부작용 가능성: 기관명 외 토큰이 적은 짧은 질의(Q11-08 "는 몇 살까지 다닐 수 있어?")에서 신호 부족.
- 수정 2 (유형 B): 기관 미감지 질의에서 재랭킹 뒤 기관당 1개를 먼저 배치. `hybrid_qstrip_diverse`.
  - 예상: 상위 5개가 5개 기관을 덮으므로 정답 기관 적중 확률 상승. 효과 크기 불확실, +0.00~+0.03.
- 유형 C 는 이번 수정 범위 밖(코퍼스 변경 필요). 기록만.

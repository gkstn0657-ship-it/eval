- 파이프라인: vanilla(chat_rag: ko-sbert-nli 단일 벡터, 임계값 0.5) / hybrid(hybrid-search-eval: bge-m3 + BM25 → RRF k=60 → 기관 필터 → bge-reranker-v2-m3 상위 30)

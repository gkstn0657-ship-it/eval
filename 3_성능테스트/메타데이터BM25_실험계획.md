# 메타데이터 BM25 실험: 기관 필터 없이 기관을 가려낼 수 있는가 (사전등록, 2026-10-06 작성, 측정 전)

## 배경

하이브리드 검색에서 기관 필터를 빼면 nDCG@5 가 0.77 → 0.46 으로 떨어졌다(20개 기관 코퍼스). 확인해 보니 조문 본문에 기관명이 거의 없다(전체 조문의 2.4%, dev 정답 조문 51개 중 0개). 질의의 "도로공사"는 키워드인데 맞출 단어가 본문에 없어서 BM25 도 dense 도 기관을 가릴 수 없었다. 필터는 메타데이터(org 필드)로 이 연결을 대신 만들어 준 것이다.

질문: 필터를 빼고, 메타데이터를 BM25 의 검색 대상에 넣어서 필터의 성능을 대신할 수 있는가.

## 원칙

- 기존 파이프라인 파일(`run_eval.py` 등)은 수정하지 않는다. 새 스크립트 `run_meta_bm25.py` 에 따로 구현하고 공통 함수(코퍼스 로딩, 채점, 모델 로딩)만 가져다 쓴다.
- 새 조건에는 기관 필터(사전·사후 모두)와 기관 별칭 사전을 쓰지 않는다. 기관명 변형은 규칙으로만 만든다.
- 질의는 원문 그대로 쓴다(기관명 제거 없음).

## 조건

| ID | 이름 | 구성 |
|---|---|---|
| B0 | `hybrid_nofilter` (기존) | dense + BM25(본문) → RRF → CE. 필터 없음. 하한 기준 |
| B1 | `hybrid_prefilter` (기존) | 별칭 사전으로 기관 추출 → 기관 조문으로 먼저 자름 → dense + BM25 → RRF → CE. 목표 기준 |
| M1 | `meta_concat` | BM25 색인 텍스트 앞에 `[기관] 기관명 + 규칙 변형`을 붙임. dense·CE 는 본문 그대로 |

규칙 변형: 앞의 "한국", "(주)", "주식회사", "(사)", "(재)" 와 뒤의 "(주)" 를 뗀 형태. 예: 한국도로공사 → 도로공사.


## 고정 변수

| 항목 | 값 |
|---|---|
| 코퍼스 | `L2P_A` (최신판, 개정이력 접두어·정의 조항 분할). 현재 저장소 기준 292개 기관, 22,336청크 |
| 부분 코퍼스 | 같은 `L2P_A` 에서 기존 실험의 20개 기관만 남긴 것(이전 수치와 연결용) |
| 모델·상수 | bge-m3, bge-reranker-v2-m3, dense·BM25 각 30, RRF k=60, CE 상위 30. 기존과 동일 |
| 평가 세트 | dev(채점 40문항, 질의에 기관명 있음), employee(채점 40문항, 질의에 기관명 없고 `context_org` 로 소속을 앎) |
| employee 세트의 기관 정보 | B1 은 `context_org` 를 필터에 쓴다. B0·M1 은 `context_org` 기관명을 질의 문자열 뒤에 붙인다(필터 없이 같은 정보를 텍스트로 전달). B0 에도 붙여야 B0 와 M 의 차이가 색인 방식 하나로 좁혀진다 |
| 홀드아웃 | 열지 않는다 |

## 지표와 판정

- 주 지표 nDCG@5, 보조 Recall@5, MRR. 진단 지표: 상위 5개 중 정답 기관 조문 비율(기관 적중률).
- 쌍대 부트스트랩 2,000회, 95% 신뢰구간. 비교: M1 vs B0(필터 없음 대비 개선), vs B1(필터 대체 가능성).
- **판정**: M1 이 B0 보다 유의하게 높고, B1 과의 차이가 유의하지 않으면 "필터를 대체할 수 있다". B1 보다 유의하게 낮으면 "부분 대체"로 본다.
- 판정은 292개 기관 코퍼스의 두 세트를 기준으로 한다. 20개 기관 부분 코퍼스는 이전 수치와의 연결용 참고다.

## 변경 기록

- 2026-10-06 측정 도중 범위 축소: 사용자 요청은 "메타데이터를 BM25 검색 대상에 포함" 하나였다. 계획에 덧붙였던 M2(기관명 글자 단위 별도 필드)·M3(재랭커 입력에 기관명)와 가중치 민감도는 요청 밖이라 결과를 보기 전에 제거했다. 조건은 B0·B1·M1 셋.

# 2차: 원인 분석 실험 (사전등록, 2026-10-06 작성, 측정 전)

1차 결과: 기관명을 BM25 색인에 넣어도 292개 기관 0.19 → 0.25, 20개 기관 0.46 → 0.46. 사전 필터는 0.88~0.93. 왜 대신하지 못하는지 원인을 가설로 나누고 각각 따로 검증한다.

## 가설

| ID | 가설 | 이론적 근거 |
|---|---|---|
| H1 | **신호 희석**: 기관명은 질의 토큰 1~2개뿐이라 BM25 합산 점수에서 주제 토큰들에 밀린다 | BM25 는 질의 토큰별 점수를 더한다. 기관 토큰 IDF 는 log(기관 수) 수준으로 제한되고, 다른 기관 조문이 주제 토큰을 더 많이 맞히면 가산점을 넘어선다 |
| H2 | **어휘 불일치**: 질의의 기관 표현이 색인의 기관명 토큰과 맞지 않는다 | 정규식 토큰화에서 "제주개발센터"와 "제주국제자유도시개발센터"는 다른 토큰 |
| H3 | **융합 희석**: RRF 에서 기관을 모르는 dense 후보 30개가 섞인다 | 후보의 절반이 기관 신호와 무관 |
| H4 | **재랭커 무지**: 최종 순위를 정하는 재랭커가 본문만 보고 기관을 모른다 | 기관만 다른 거의 같은 조문은 재랭커 점수도 거의 같다 |
| H5 | **점수 대 제약**: 필터는 "다른 기관 제외"라는 제약이고 BM25 는 유한한 가산점이다 | 가산점 가중치를 무한대로 키우면 필터와 같아진다. 유한한 가중치에서는 동형 문서 수가 많을수록 뚫린다 |

## 조건 (모두 기관 필터 없음, 별칭 사전 없음)

| ID | 구성 | 검증 가설 |
|---|---|---|
| E0 | 필터 없는 하이브리드 (= B0) | 기준 |
| E1 | BM25 색인에 기관명 (= M1) | 1차 결과 재현 |
| E2a / E2b | E1 + 질의 속 기관 토큰을 BM25 질의에서 3배 / 10배 가중 | H1, H5 (가중치를 키우면 필터에 가까워지는가) |
| E3 | E1 의 BM25 후보만 사용 (dense 제외) | H3 |
| E4 | E1 + 재랭커 입력 앞에 `[기관] 기관명` | H4 |
| E5 | E2b + E3 + E4 (모든 보정을 합친 최선의 소프트 방식) | 소프트 점수로 필터에 도달 가능한가 |
| B1 | 사전 기관 필터 (기존) | 목표 |

질의 속 기관 토큰은 사전 없이 정한다: 질의 토큰 중 색인의 기관명 토큰 집합에 있는 것.

## 측정 지표 (단계별)

- 후보 단계(RRF 상위 30, E3·E5 는 BM25 상위 30): 정답 조문 포함률, 정답 기관 비율
- 최종 단계(상위 5): nDCG@5, Recall@5, 정답 기관 비율
- H1 진단: E1 에서 정답 조문의 BM25 점수 중 기관 토큰 몫, 정답 조문보다 BM25 점수가 높은 다른 기관 조문 수
- H2 진단: 질의의 기관 표현이 색인 기관명 토큰과 하나라도 일치하는 문항 비율

## 판정

- 후보 단계 지표가 크게 오르는데 최종 지표가 그대로면 H4 가 주원인.
- E2 에서 가중치를 키울수록 후보 단계가 필터 수준(정답 기관 비율 90% 이상)에 다가가면 H1·H5 지지.
- E3 이 E1 보다 후보 단계 정답 기관 비율이 높으면 H3 지지.
- E5 가 B1 과 유의한 차이가 없으면 "소프트 방식도 보정하면 대체 가능", 유의하게 낮으면 "대체 불가".
- 평가: 292개 기관 dev(주), 20개 기관 dev(보조), 292개 기관 employee(보조, 질의에 소속 기관명 덧붙임). 홀드아웃은 열지 않는다. dev 로 설정을 고르지 않고 원인만 진단한다.

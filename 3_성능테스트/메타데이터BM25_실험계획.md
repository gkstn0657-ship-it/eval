# 메타데이터 BM25 실험: 기관 필터 없이 기관을 가려낼 수 있는가 (사전등록, 2026-10-06 작성, 측정 전)

## 배경

하이브리드 검색에서 기관 필터를 빼면 nDCG@5 가 0.77 → 0.46 으로 떨어졌다(20개 기관 코퍼스). 확인해 보니 조문 본문에 기관명이 거의 없다(전체 조문의 2.4%, dev 정답 조문 51개 중 0개). 질의의 "도로공사"는 키워드인데 맞출 단어가 본문에 없어서 BM25 도 dense 도 기관을 가릴 수 없었다. 필터는 메타데이터(org 필드)로 이 연결을 대신 만들어 준 것이다.

질문: 필터를 빼고, 메타데이터를 BM25 의 검색 대상에 넣어서 필터의 성능을 대신할 수 있는가.

## 원칙

- 기존 파이프라인 파일(`run_eval.py` 등)은 수정하지 않는다. 새 스크립트 `run_meta_bm25.py` 에 따로 구현하고 공통 함수(코퍼스 로딩, 채점, 모델 로딩)만 가져다 쓴다.
- 새 조건에는 기관 필터(사전·사후 모두)와 기관 별칭 사전을 쓰지 않는다. 기관명 변형은 규칙으로만 만든다.
- 질의는 원문 그대로 쓴다(기관명 제거 없음).

## 조건

| ID | 이름 | 구성 |
|---|---|---|
| B0 | `hybrid_nofilter` (기존) | dense + BM25(본문) → RRF → CE. 필터 없음. 하한 기준 |
| B1 | `hybrid_prefilter` (기존) | 별칭 사전으로 기관 추출 → 기관 조문으로 먼저 자름 → dense + BM25 → RRF → CE. 목표 기준 |
| M1 | `meta_concat` | BM25 색인 텍스트 앞에 `[기관] 기관명 + 규칙 변형`을 붙임. dense·CE 는 본문 그대로 |
| M2 | `meta_field` | BM25 점수 = 본문 BM25(최대값 정규화) + w × 기관 필드 BM25(최대값 정규화). 기관 필드는 기관명을 글자 2-gram 으로 쪼갠 별도 색인. w = 1 |
| M3 | `meta_field_ce` | M2 + CE 입력 앞에 `[기관] 기관명` 을 붙여 재랭커도 기관을 보게 함 |

규칙 변형(M1, M2 공통): 앞의 "한국", "(주)", "주식회사", "(사)", "(재)" 와 뒤의 "(주)" 를 뗀 형태. 예: 한국도로공사 → 도로공사.

글자 2-gram 을 쓰는 이유: 정규식 토큰화에서는 "한국도로공사" 와 "도로공사" 가 다른 토큰이고, "제주개발센터" 는 "제주국제자유도시개발센터" 와 토큰이 하나도 겹치지 않는다. 2-gram 이면 "제주·개발·발센·센터" 가 겹친다. "LH", "HUG" 같은 영문 약칭은 사전 없이는 잡을 수 없으며 이것이 이 방식의 알려진 한계다.

| 홀드아웃 | 열지 않는다 |

## 지표와 판정

- 주 지표 nDCG@5, 보조 Recall@5, MRR. 진단 지표: 상위 5개 중 정답 기관 조문 비율(기관 적중률).
- 쌍대 부트스트랩 2,000회, 95% 신뢰구간. 비교: M1·M2·M3 각각 vs B0(필터 없음 대비 개선), vs B1(필터 대체 가능성).
- **판정**: M 조건이 B0 보다 유의하게 높고, B1 과의 차이가 유의하지 않으면 "필터를 대체할 수 있다". B1 보다 유의하게 낮으면 "부분 대체"로 본다.
- 판정은 292개 기관 코퍼스의 두 세트를 기준으로 한다. 20개 기관 부분 코퍼스는 이전 수치와의 연결용 참고다.
- 민감도(탐색, 판정에 쓰지 않음): M3 에서 w = 0.5, 2.

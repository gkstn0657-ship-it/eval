# 1_데이터셋

세 파이프라인(chat_rag, hybrid-search-eval, multimodal-rag)의 성능을 같은 기준으로 측정하기 위한 데이터셋.
기준 raw 데이터는 **공기업 인사규정 HWP 원본**이다.

## 왜 공기업 인사규정 HWP인가

- 현업(클라이언트·부서)이 넘기는 문서는 HWP·DOCX·PDF이고, 현재 chat_rag는 txt·md·pdf만 받는다. 간극이 가장 큰 곳에서 시작한다.
- 인사규정은 조·항·호 계층, 별표·서식, 개정 이력이 붙어 있어 "조항 단위로 끊어야 한다"는 설계 주장을 실제로 검증할 수 있다.
- 공공기관 내부규정은 ALIO(공공기관 경영정보 공개시스템)에 공개돼 있어 재현 가능하고, 같은 규정의 여러 개정판이 함께 올라와 near-duplicate 방해 문서를 자연스럽게 얻는다.

## 레이어 구성

| 폴더 | 내용 | 원칙 |
|---|---|---|
| `01_raw/` | ALIO에서 받은 원본 그대로 | 수정 금지. `manifest.jsonl`에 출처·해시·수집일 기록 |
| `02_parsed/` | HWP·PDF → 텍스트·구조 변환 결과 (파서별) | 파서 선택도 실험 변수 |
| `03_clean/` | 머리글·바닥글 제거, 표 직렬화, 정규화 | 규칙마다 "안 하면 실패하는 질의" 명시 |
| `04_eval/` | 질의셋, 골든 라벨, 사전등록 | 측정 전 확정 |

정제(02, 03)는 숨기는 전처리가 아니라 측정 대상이다. raw 파싱만 한 조건과 정제 후 조건을 나란히 재서 정제의 기여를 숫자로 보인다.

## 01_raw 수집 결과 (2026-10-01)

| 세트 | 기관 수 | 파일 수 | 비고 |
|---|---|---|---|
| `공기업_인사규정_HWP/` | 12 | 33 | 기준 세트. 기관별 최신 3개 개정판까지 (hwp·hwpx 혼재) |
| `공기업_인사규정_PDF/` | 8 | 8 | 보조 세트. HWP 없이 PDF만 공시한 기관의 최신판 |

대상은 ALIO 분류 "인사·복무·징계" 중 제목이 정확히 "인사규정"인 시장형·준시장형 공기업 22개.
한전KPS·한국지역난방공사는 zip만 제공해 제외. 시행세칙·별정직 규정은 제외.

수집 스크립트: `scripts/fetch_alio_hwp.py`, 당일 목록 스냅샷: `scripts/alio_인사규정_목록_20261001.json`.

## 수집 과정 기록

1. 한국전력 사규 페이지(kepco.co.kr)를 먼저 시도했으나 다운로드 파라미터가 JS 암호화 토큰이어서 직접 수집 실패.
2. ALIO 내부규정 목록 API(`/occasional/findRuleList.json`)와 다운로드 엔드포인트(`/download/rulefiledown.json?fileNo=`)를 확인해 수집.
3. 기관유형 코드 A2001=시장형 공기업, A2002=준시장형 공기업으로 필터.

## 라이선스

ALIO 공개 내부규정이다. 포트폴리오 공개 레포에 포함하기 전 각 기관의 공공누리 유형을 확인해야 한다. 확인 전까지는 manifest의 URL로 재수집 가능하도록 하고, 원본 파일 재배포 여부는 보류한다.

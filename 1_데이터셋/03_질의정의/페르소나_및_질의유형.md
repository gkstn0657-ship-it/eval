# 페르소나 정의와 질의 유형

실제 사용자 질의를 수집할 수 없으므로, 공기업 인사규정 RAG의 사용자를 페르소나로 정의하고
각 페르소나의 요구사항에서 질의 유형을 추출한다. 이 질의 유형은 문서 정제 기준(04_정제규칙)의 입력이 된다.

대상 문서: 공기업 인사규정 (01_raw, 20기관 41파일, 기관별 최신 1~3개 개정판)

## 1. 페르소나

| ID | 페르소나 | 상황 | 요구사항 | 답의 조건 |
|---|---|---|---|---|
| P1 | 일반 직원 (입사 3년차) | 휴직·승진·전보 등 본인 신분 변동 시 규정 확인 | 내 상황에 적용되는 조항과 요건을 빠르게 확인 | 조항 번호와 원문 근거. 현재 유효한 개정판 기준 |
| P2 | 인사담당자 (실무) | 임용·승진·징계 처리 시 절차와 기한 확인, 서식 준비 | 절차 단계, 기한, 심의기구, 필요 서식 | 조·항·호 단위 정확한 인용. 별표·서식 참조 가능 |
| P3 | 인사담당자 (제도 개선) | 타 기관 규정과 비교해 개정안 작성 | 동일 주제의 기관 간 차이, 개정 전후 차이 | 기관·개정일 메타데이터로 비교 가능 |
| P4 | 감사·법무 | 특정 처분의 규정 근거와 개정 시점 검증 | 해당 조항의 당시 유효 문구와 개정 이력 | 개정 표기와 부칙으로 시점 특정 |
| P5 | 신규 입사자 | 용어와 제도 자체를 모름 | 용어 정의, 제도 개요, 어디에 적혀 있는지 | 정의 조항 우선. 없는 내용은 "없다"고 답 |

## 2. 질의 유형

| 유형 | 설명 | 예시 질의 | 주 페르소나 | 답이 있는 문서 구조 |
|---|---|---|---|---|
| Q1 조항 조회 | 특정 조항 또는 주제의 원문 확인 | "휴직 사유를 알려줘", "제15조 내용이 뭐야" | P1, P5 | 본문 조·항·호 |
| Q2 요건 판단 | 조건 충족 여부 판단 | "육아휴직은 몇 년까지 가능해?", "승진 최저 소요 연수는?" | P1, P2 | 본문 항·호, 별표(소요연수표) |
| Q3 수치 확인 | 기간·일수·인원·비율 등 숫자 | "직위해제 기간은?", "시간선택제 근무시간 하한은?" | P1, P2 | 본문 숫자, 표 셀 |
| Q4 절차·기한 | 처리 순서, 심의기구, 기한 | "징계 요구는 누가 하고 어디서 심의해?", "복직 신청은 며칠 전까지?" | P2 | 본문 절차 조항, 별지 서식 |
| Q5 용어 정의 | 규정 내 용어의 뜻 | "승격과 승진의 차이는?", "임용의 범위는?" | P5 | 총칙 정의 조항 |
| Q6 기관 간 비교 | 동일 주제의 기관별 차이 | "휴직 기간 상한이 가장 긴 기관은?", "A사와 B사 승진 심사 방식 차이" | P3 | 여러 문서의 동일 주제 조항 + 기관 메타데이터 |
| Q7 개정 이력 | 언제 어떻게 바뀌었는지 | "2025년에 바뀐 조항은?", "제20조는 언제 신설됐어?" | P3, P4 | 개정 표기 `<개정 2025.1.1>`, 부칙 |
| Q8 서식·별표 참조 | 별표·서식 내용 | "승진 소요 연수표를 보여줘", "휴직 신청서 양식은?" | P2 | 별표, 별지 서식 (표 구조) |
| Q9 범위 외 질의 | 규정에 없는 내용 | "연봉 테이블은?", "복지포인트는 얼마야?" (보수·복지 규정 소관) | P1, P5 | 없음. "이 규정에 없다"가 정답 |
| Q10 삭제·폐지 조항 | 삭제된 조항에 대한 질의 | "제30조는 왜 비어 있어?" | P4 | `제30조 삭제 <2020.1.1>` 표기 |
| Q11 일상어 질의 (키워드 불일치) | 규정 용어를 모르고 상황을 일상어로 설명. 질의에 규정의 핵심 단어가 하나도 없음 | 아래 표 참조 | P5, P1 | 본문 조·항 + 정의 조항 + 조 제목. 질의어와 문서어 사이에 용어 매핑 필요 |

### Q11 일상어 질의 예시

규정 용어와 질의어가 겹치지 않아 키워드 검색이 실패하는 유형. 의미 검색과 용어 매핑을 함께 검증한다.

| 일상어 질의 | 실제로 찾아야 할 규정 용어 | 답이 있는 구조 |
|---|---|---|
| "아기 낳으면 회사 얼마나 쉴 수 있어?" | 출산전후휴가, 육아휴직 | 휴직 조항, 휴직 기간 |
| "회사 잠깐 쉬고 싶은데 가능해?" | 휴직 (청원휴직, 직권휴직) | 휴직 사유·기간 조항 |
| "다른 부서로 옮기고 싶으면 어떻게 해?" | 전보, 전직, 보직 변경 | 전보 조항, 전보 제한 기간 |
| "윗 직급으로 올라가려면 몇 년 걸려?" | 승진, 승진 소요 최저 연수 | 승진 조항, 별표 소요연수표 |
| "일 잘못하면 어떤 벌을 받아?" | 징계 (파면·해임·정직·감봉·견책) | 징계 종류 조항 |
| "회사에서 잘릴 수 있는 경우가 뭐야?" | 면직, 직권면직, 당연퇴직, 결격사유 | 면직·퇴직 조항 |
| "입사하고 처음 몇 달은 정식 직원이 아니야?" | 수습, 시용, 수습기간 | 신규채용·수습 조항 |
| "병 걸려서 오래 못 나오면 어떻게 돼?" | 질병휴직, 직권휴직, 휴직 기간 만료 | 휴직 조항 |
| "일 하다가 자리를 뺏기는 경우도 있어?" | 직위해제, 대기 | 직위해제 조항 |
| "대학원 다니면서 일할 수 있어?" | 휴직(연수·학업), 겸직 제한 | 휴직 사유, 겸직 조항 |
| "친척이 같은 회사에 있으면 안 돼?" | 친족 관계 보직 제한, 결격사유 | 보직 제한 조항 |
| "다른 회사 일을 같이 해도 돼?" | 겸직 금지, 영리업무 제한 | 복무 관련 조항 (없으면 Q9 범위 외) |

판정 기준: 질의 단어가 정답 조문에 0개 또는 1개만 포함된 경우를 Q11로 분류한다. 평가셋 작성 시 이 기준으로 Q1과 구분한다.

## 3. 질의 유형이 정제 기준에 주는 요구

| 요구 | 근거 질의 유형 | 정제 시 보존·구조화 대상 |
|---|---|---|
| 조항 번호와 제목을 정확히 보존 | Q1, Q2, Q4, Q10 | `제N조(제목)` 패턴, `제N조의M` 삽입조 |
| 항·호·목 번호 체계 유지 | Q1, Q2, Q4 | ①②③, 1. 2., 가. 나. |
| 숫자와 단위를 변형 없이 보존 | Q2, Q3 | 기간, 일수, 비율, 인원 |
| 표를 셀 구조가 남는 형태로 직렬화 | Q3, Q8 | 별표의 소요연수표, 정원표 |
| 개정 표기를 본문에서 분리해 메타데이터로 | Q7, Q4 | `<개정 2025.1.1>`, `<신설>`, `<삭제>` |
| 부칙을 본문과 분리하고 개정일 추출 | Q7, Q4 | 부칙 블록, 시행일 |
| 기관명·개정일을 문서 메타데이터로 | Q6, Q7 | 파일명, 표지, manifest |
| 삭제 조항을 제거하지 않고 표기 유지 | Q10 | `제N조 삭제` |
| 다른 규정 소관 사항을 답하지 않도록 범위 명시 | Q9 | 규정 제목, 적용범위 조항 |
| 조 제목과 정의 조항을 검색 단위에 붙여 보존 | Q11, Q5 | `제N조(휴직)` 제목, 총칙 용어 정의 |
| 일상어 ↔ 규정어 용어 사전 구축 | Q11 | 정의 조항·조 제목에서 규정어 추출, 일상어 대응 표현을 사람이 추가 |

## 4. 보류 사항

- 청킹 단위는 이 단계에서 정하지 않는다. 위 요구는 "무엇을 지우지 말 것인가"의 기준이다.
- 질의 예시는 평가셋이 아니다. 평가 질의는 04_eval 단계에서 사전등록 후 작성한다.

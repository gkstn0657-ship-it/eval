# 가드레일 정책 v2 (2026-10-06)

기존 정책(`정책.md`, 키워드 분류·재랭커 점수 게이트·출력 검증)은 폐기한다. 외부 질문 200건에서 오거절 32%, 점수 신호의 일상어 분리력 AUC 0.60 으로 쓸 수 없다고 확인됐다(`가드레일_결과.md`). 이 문서는 처음부터 다시 세운 정책이다.

## 1. 원칙

1. **틀린 답보다 안 하는 답이 낫다.** 인사규정 답변은 휴직·징계·퇴직 같은 개인의 결정에 쓰인다. 지어낸 답의 비용이 거절의 비용보다 크다.
2. **그러나 거절은 막다른 길이 되면 안 된다.** 거절할 때는 이유와 다음 행동(소관 규정, 후보 조항, 인사부서)을 함께 준다.
3. **모든 답에는 근거가 붙는다.** 기관명·조번호·개정일을 밝혀 사용자가 직접 확인할 수 있게 한다.
4. **판단 기준은 측정으로 고른다.** 신호가 거절할 질문과 답할 질문을 가르는지 먼저 확인하고, 가르는 신호로만 게이트를 만든다.

## 2. 서비스 범위

| 범위 안 | 범위 밖 |
|---|---|
| 해당 기관 인사규정 본문에 있는 사항: 채용·수습, 임용, 승진, 전보, 휴직·복직, 징계 절차, 직위해제, 퇴직·정년, 인사위원회 등 | 다른 규정 소관: 보수·수당, 복무(연차·근무시간), 여비, 복리후생, 교육훈련 세부 등 |
| | 개인 사안의 결과 판단: "제가 잘릴까요?", "이 경우 징계 몇 개월 나와요?" |
| | 법률 해석·소송 자문, 규정과 무관한 질문 |

## 3. 위험 유형별 처리

| 유형 | 판정 | 처리 | 응답 방향 |
|---|---|---|---|
| **R1 범위 밖 (다른 규정 소관)** | 기관 인사규정의 위임 규정 목록과 질문 주제 대조 | 답변하지 않음 | "인사규정이 아니라 ○○규정 소관입니다" + 소관 규정명 |
| **R2 근거 없음** | 검색된 조문에 질문의 답이 없음 | 답변하지 않음 | "인사규정에서 찾지 못했습니다" + 가장 가까운 조항 후보 3개 |
| **R3 근거 일부** | 답의 일부만 조문에 있음 | 확인된 부분만 답 | 확인되지 않은 부분은 "규정에 명시 없음"으로 구분 |
| **R4 기관 불명** | 질문과 사용자 정보에서 기관을 특정할 수 없음 | 검색 전 되묻기 | "어느 기관 규정을 찾을까요?" (사내 챗봇은 소속 기관을 기본값으로) |
| **R5 개인 사안 판단 요청** | 특정인의 결과를 단정해 달라는 질문 | 판단은 하지 않고 규정 내용만 | 해당 조문 요약 + 원문 + "적용 여부는 인사부서 판단" |
| **R6 지시 무력화·악용** | 시스템 지시 무시 요청, 개인정보 입력 | 해당 요청 거부 | 규정 질문으로 유도, 개인정보 입력 경고 |

공통: 모든 답변에 근거 조문(기관·조번호·개정일)과 면책 문구("자동 생성된 참고 정보이며 최종 적용은 인사부서 확인")를 붙인다. 최신판 기준임을 밝힌다.

## 4. 판정 위치

```
질문 → [입력] R4 기관 불명, R6 악용, R1 범위 밖
     → 검색 (기관 사전 필터 + 하이브리드 + 재랭커)
     → [근거] 생성 모델이 조문을 근거로 답할 수 있는지 판단 → R2, R3
     → 답변 생성 (근거 인용 의무)
     → [출력] 답변의 조번호·숫자가 근거 조문에 있는지 검증 → 어긋나면 R2 처리
     → [응답] R5 해당 시 단정 표현 제거, 근거·면책 첨부
```

## 5. 측정 지표와 목표 (측정 전 고정)

| 지표 | 정의 | 목표 |
|---|---|---|
| 거절 재현율 | 거절해야 할 질문(범위 밖·정답 없음) 중 거절한 비율 | 80% 이상 |
| 오거절률 | 답해야 할 질문 중 거절한 비율 | 10% 이하 |
| 근거 없는 답변률 | 답한 것 중 조문에 없는 내용을 포함한 비율 (사람 검수 표본) | 5% 이하 |
| 소관 안내 정확도 | 범위 밖 거절 중 소관 규정을 맞게 안내한 비율 | 70% 이상 |

목표는 원칙 1에 따라 비대칭이다. 근거 없는 답변을 가장 엄격하게 본다.

## 6. 평가 데이터

- 기본: 외부 AI가 쓴 질문 200건, 사람 라벨(R 답해야 함 82, W 답 있는데 검색 실패 27, NA 정답 없음 51, OUT 범위 밖 40). 설계용 100, 봉인용 100 으로 라벨·말투 비율을 맞춰 나눈다.
- 보충 필요: R4·R5·R6 유형은 현재 데이터에 거의 없다. 설계 전에 각 20건 이상 작성한다.
- 기존 평가 세트(dev, employee, FAQ, matrix)는 오거절률 측정에만 보조로 쓴다.

## 7. 운영 판단이 필요한 사항

- R5 범위: "징계 시효가 몇 년이냐" 같은 정보성 질문은 일반 답변을 허용하고, 특정인 결과 단정만 막는 것으로 제안한다.
- R1 소관 안내를 기관별 실제 규정명으로 할지, 일반 문안으로 할지.
- 공개 데모에 적용할지, 사내 챗봇 시나리오에만 적용할지.

## 검토 (2026-10-06)

정책을 세운 뒤 스스로 점검한 결과다.

### 일관성·실행 가능성

| 점검 항목 | 결과 | 조치 |
|---|---|---|
| 라벨과 유형 대응 | NA·OUT 은 R1·R2 로 대응되지만, **W(답이 있는데 검색 실패)** 는 정책상 R2 로 거절된다. 사용자에게는 오답이 아니라 "못 찾음"이 되므로 실패가 아니다. 그러나 오거절로 셀지 정해져 있지 않다 | W 는 오거절률 분모에서 빼고, "후보 3개 안에 정답 조항이 있었는가"를 따로 잰다 |
| R1 판정 근거 | 위임 규정 목록은 기관마다 있지만 질문을 그 목록에 대조하는 방법이 정해지지 않았다. 키워드 대조로 가면 폐기한 방식으로 돌아간다 | 판정 방식은 신호 분리력 측정 후 결정. 키워드 단독은 금지 |
| R2 판정 근거 | "생성 모델이 판단"은 4B·7B 판정자가 실패한 전례가 있다 | 14B 실험 답변으로 분리력을 먼저 잰다. 분리력이 낮으면 R2 자동 거절을 하지 않고 "근거 확인 권고" 표시로 낮춘다 |
| R4 와 기관 비교 질문 | 기관 비교 질문("정년 61세인 기관 있어?")은 R4 로 되묻게 되는데, 이는 라우팅 과제와 겹친다 | 비교 질문은 R4 에서 제외하고 "비교 미지원" 안내로 처리. 라우팅 구현 시 해제 |
| 출력 검증 | 조번호·숫자 대조는 규칙이라 측정 없이도 동작하지만, 숫자가 맞아도 문장 뜻이 틀린 경우는 못 잡는다 | 근거 없는 답변률을 사람 검수로 재서 규칙의 한계를 수치로 남긴다 |

### 목표치

- 80% / 10% 는 기존 실험의 최선값(거절 71%, 오거절 32%)보다 훨씬 높다. 현재 부품으로 도달 가능한지는 모른다. 측정 후 미달이면 목표를 낮추지 않고 "미달"로 기록한다.
- 근거 없는 답변률 5% 는 사람 검수 표본 크기에 따라 신뢰구간이 넓다. 최소 50건을 검수한다.

### 빠진 것

- 응답 시간 상한이 없다. 판정 단계가 늘면 지연이 커진다. 목표: 판정 추가로 응답 시간 2초 이상 늘리지 않기.
- 거절 문안의 사용자 수용도는 재지 않는다. 포트폴리오 범위 밖으로 둔다.

### 결론

정책 자체는 실행 가능하지만, **R1 과 R2 의 판정 방식이 아직 정해지지 않은 것이 핵심 공백**이다. 두 판정은 신호 분리력 측정 결과에 따라 결정하며, 그 전까지는 출력 검증과 근거 제시만 적용한다.

# 상황 공유: 공공기관 인사규정 RAG의 가드레일 실험 (2026-10-05)

다른 AI(아스트라)에게 현재 상황을 전달하기 위한 문서. 네가 만들어 준 질문 200개가 어떻게 쓰였고 무엇이 드러났는지까지 포함한다.

## 1. 무엇을 만들고 있나

- 공공기관 292곳의 인사규정(조문 단위 22,336청크)을 검색해 직원 질문에 답하는 사내 챗봇.
- 사용자는 자기 회사만 묻는다고 가정. 질문에 회사명은 없고, 로그인 정보처럼 회사가 따로 주어진다.
- 답변은 검색된 조문만 근거로 하고, 규정에 없는 내용은 "없다"고 해야 한다.

## 2. 검색 파이프라인 (확정, 성능 검증 끝)

```
질문 + 회사 → 그 회사 조문만 남김 → 임베딩 검색(bge-m3) + 키워드 검색(BM25) → 순위 융합(RRF)
→ 상위 30개를 교차 인코더 재랭커(bge-reranker-v2-m3)로 재정렬 → 상위 5개
```

- 핵심은 "회사 필터를 검색 앞단에 두는 것". 292곳 전체에서 찾으면 nDCG@5 0.26, 회사 안에서만 찾으면 0.89~0.99.
- 평가셋: 사람이 쓴 질문 242개(기관 18곳) + 실제 FAQ 기반 44개 + 자동 생성 111개 + 범위 밖 123개.
- 남은 검색 약점: 기관 두 곳을 비교하는 질문(nDCG 0.20), 일상어 ↔ 규정어 간극(예: "정족수" vs "재적 3분의 2 출석").

## 3. 가드레일 구성 (지금 실험 중)

문제: 검색은 잘 되지만 답할 수 없는 질문에도 항상 상위 5개를 내놓는다. 범위 밖 질문 123개에서 거절률 0%.

```
질문
 → [G1 입력 분류] 키워드 규칙
     범위 밖(연차·성과급·여비·퇴직금·육아시간…) → 즉시 거절 안내
     고위험(징계·해고·성비위) → 검색은 하되 생성 답변 없이 조문 원문만
     기관명 2개 이상 → "하나씩 질문해 달라" 안내
 → [검색]
 → [G2 검색 게이트] 재랭커 1위 점수(0~1)
     0.30 이상 → 통과
     0.05 미만 → 거절 후보
     0.05~0.30 → 회색
     회색·거절 후보 → 2차 판정: 로컬 LLM에게 "상위 3개 조문 중 질문에 답이 실제로 적혀 있는가" 예/아니오
 → [생성] 로컬 LLM, 조문만 근거로 답변
 → [G3 출력 검증] 답변의 숫자+단위(60세, 3년…)가 근거 조문에 있는지, 인용 조문 번호가 전달한 것인지 정규식 대조. 어긋나면 답변 폐기하고 원문만 표시
 → [화면] 근거 조문·면책 문구·신고 버튼
```

- 2차 판정 모델: SKT A.X 4.0 Light 7B(Qwen2.5 기반 한국어 추가 학습), 4비트, CPU 전용. 건당 약 21초.
- 처음 쓴 Qwen3 4B는 76건 중 73건에 "아니오"를 답해 폐기. 조문을 450자로 잘라 준 것과 모델 크기를 동시에 바꿔 개선했기 때문에 원인은 분리하지 못했다.

## 4. 지금까지 결과

### 우리 평가셋(388건)에서

| 지표 | 게이트 전 | 1단계(키워드·점수) | 2단계(LLM 판정) 포함 |
|---|---|---|---|
| 정답 없는 질문 139건 거절 | 0% | 99% | 99% |
| 정답 있는 질문 249건 오거절 | - | 9.6% | 4.4% |

- 재랭커 점수는 정답 없음(최대 0.07)과 정형 질문 정답(최소 0.73)은 깨끗이 가르지만, 자연어 질문은 정답을 맞혀도 0.001까지 떨어진다. 그래서 임계값 단독으로는 안 되고 2차 판정이 필요했다.

### 네가 만든 200개 질문에서 (가스안전공사 기준, 측정 완료)

가장 나쁜 숫자부터. **답이 있고 검색도 맞힌 질문 82건 중 26건(32%)을 거절했다.** 직원 셋 중 하나가 "규정에 없습니다"라는 틀린 안내를 받는 셈이라 이 설정은 실사용 불가다.

| 사람 라벨 \ 최종 처리 | 거절 | 답변(원문만 포함) | 합계 |
|---|---|---|---|
| 거절해야 함 (범위 밖 40 + 규정에 답 없음 51) | **65** | 26 | 91 |
| 답해야 함 (답 있고 검색 성공) | **26** | 56 | 82 |
| 별도: 답 있는데 검색 실패 | 18 | 9 | 27 |

- 거절률 71%(65/91), 오거절률 32%(26/82). 검색이 놓친 27건 중 18건은 거절돼 틀린 답이 나가는 건 막았다.
- 2차 LLM 판정은 양날이었다. 오거절을 61%→32%로 절반 줄였지만, 거절률도 82%→71%로 깎았다(답 없는 질문 11건을 "답 있다"고 되살림).
- 오거절은 말투에 몰린다. 상황설명 45%(5/11), 일상어 38%(13/34), 오타 35%(7/20), 전문용어 6%(1/17).
- 질문 품질: 회사명 0건, 유사 중복 0건, 스타일 비율은 요청대로. 쓸 만했고, 우리 평가셋이 못 보여준 걸 보여줬다.
- 키워드 분류(G1)의 허점: 보수복지 30건 중 14건만 걸렀다. 우리 질문은 "연차·성과급"이었는데 네 질문은 "월급·수당·이사비·지원금"이라 단어가 달랐다. 무관 질문(원두, 축사, 프린터) 10건은 하나도 못 걸렀다.
- 검색 자체(사람이 160건 읽어 판정): 답이 있는 109건 중 상위 3개 안에 정답 조문 82건(75%). 놓친 27건 중 7건이 "알바·부업·강의·판매" 질문인데 영리업무 금지 조문(제56조 8호) 대신 휴직 조문이 나왔고, 4건이 "퇴사·그만둠" 질문에 의원면직 조문(제51조)이 안 나왔다.

### 왜 안 됐나: 신호 자체가 답 유무를 모른다

측정이 끝난 뒤에야 확인한 것이고, 설계 전에 확인했어야 했다. 200건의 사람 라벨로 "답 있고 검색 성공(R) 82건"과 "답 없음(NA+OUT) 91건"을 각 신호가 얼마나 가르는지(AUC, 0.5=무정보) 쟀다.

| 신호 | AUC | 비고 |
|---|---|---|
| 재랭커 1위 점수, 전체 | 0.735 | 말투 혼합 효과 포함 |
| 〃, 일상어 안에서만 | **0.602** | 70건, 가장 큰 스타일 |
| 〃, 전문용어 안에서만 | **0.583** | 사실상 무정보 |
| 〃, 오타 안에서만 | 0.823 | 유일하게 쓸 만함 |
| 〃, 라벨 무시하고 "전문용어인가" | **0.809** | 점수는 답 유무보다 말투를 더 잘 맞힌다 |
| LLM 판정(A.X 7B), 162건 | 약 0.66 | R 정답률 61%, 답 없음 정답률 72% |
| 키워드(G1) | - | 답 없음 91건 중 14건 포착, 오탐 1건, 비용 0 |

- 임계값을 어디에 둬도 안 된다. 0.0025면 거절 50%/오거절 13%, 0.005면 62%/24%, 0.03이면 80%/50%. 둘 다 좋은 지점이 없다.
- 답이 있는데 검색이 놓친 질문(W)의 점수 중앙값 0.003과 답이 없는 질문(NA) 0.004가 같다. 점수는 "1위 조문이 질문에 답하나"만 재는데, 그 판단조차 AUC 0.72~0.73에 그친다. 재랭커가 일상어 한국어에서 관련성 자체를 못 가르는 것이고, 그 위에 어떤 게이트를 얹어도 이 한계를 못 넘는다.

### 결정: G2 폐기

- **폐기**: 재랭커 점수 임계값으로 거절을 정하는 G2, 그 위의 LLM 2차 판정.
- **유지**: G1 키워드 분류(비용 0, 어휘 보강 필요), G3 출력 검증(아직 측정 전).
- 자동 거절 대신 근거 조문을 보여주고 판단은 사용자에게 넘기는 것이 현재 부품으로는 정직한 설계다. 자동 거절을 다시 시도하려면 재랭커 교체·미세조정이나 일상어→규정어 질의 변환이 먼저고, 그때는 **신호의 라벨별 분리력을 먼저 확인한 뒤** 게이트를 설계한다.

## 5. 열려 있는 문제

1. 범위 밖 분류를 키워드로 하는 한계. 월급·수당 류 단어 추가로 일부는 막히지만, "원두 누가 채워요" 같은 무관 질문은 단어로 못 거른다.
2. (해결됨, 폐기) 점수 임계값은 출처가 아니라 말투에 반응한다는 것이 확인됐다. 2차 판정은 오거절을 절반 줄이지만 거절률도 깎아 양쪽 다 어중간하다. 4절 참조.
3. 일상어 "알바/부업" → 규정어 "영리업무·겸직"처럼 어휘가 다른 질문의 검색 실패. 용어 사전으로 질문 확장, 장 제목을 조문에 붙여 색인, 재랭커 교체 중 선택 예정.
4. 고위험 키워드가 "징계 시효가 몇 년이냐" 같은 정보성 질문까지 원문만 보여주게 만든다(정답 질문의 8~27%). 범위를 어디까지 둘지는 운영 판단.
5. 속도: 이 PC(GTX 1060 3GB, i7-8700, 램 16GB)에서 질문 하나 끝까지 약 2분. 시연과 평가용이지 실시간 서비스용이 아니다.

## 6. 측정 원칙

- 질문·정답은 측정 전에 확정하고 결과를 본 뒤 바꾸지 않는다.
- 자동 생성 질문과 사람이 쓴 질문의 점수를 따로 낸다.
- "없음"이 정답인 질문을 반드시 섞어 거절률을 같이 잰다.
- 사람이 판정한 라벨과 자동 라벨을 구분해 적는다.

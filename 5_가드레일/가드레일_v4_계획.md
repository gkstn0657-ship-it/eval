# 가드레일 v4 계획 (2026-10-12, 측정 전 고정)

v1~v3 는 폐기한다(사용자 결정). 이 문서는 v1~v3 의 측정 결과를 **근거 자료로만** 쓰고, 구조는 다시 세운다.
핵심 전환: 거부 여부를 "질문이 어떤 질문인가"로 가르던 것을 그만두고, **"고른 근거 문장이 이 질문에 답하는가"** 라는 (질문, 문장) 쌍의 검증으로 옮긴다.

## 1. 가드레일이 막는 피해 (효과의 정의)

| 피해 | 내용 | v3 까지의 상태 | v4 의 수단 |
|---|---|---|---|
| H1 지어낸 내용 | 조문에 없는 문장이 답변에 섞임 | 구조로 0 | 유지 (M1) |
| H2 엉뚱한 조문 | 실제 조문을 질문의 대상·사항이 다른데 답으로 붙임 | 거부율 91% (새는 9%) | 적용 대상 규칙 유지 + 답변성 검증 (M3, M4) + 어긋남 표시 (M5) |
| H3 답을 못 받음 | 조문에 답이 있는데 거부 | 오거부 48% | 추출기 캐스케이드 (M2) |

"효과"는 H1·H2 를 줄이면서 H3 를 같이 줄이는 것이다. 지금까지는 H2 와 H3 가 같은 곡선 위에서 자리만 바꿨다(7B 91%/48%, 14B 70%/17%). v4 의 성공 기준은 **이 곡선을 벗어나는 것**이다.

## 2. 설계 원칙 (측정 결과에서 도출)

1. 모델에게 "판단"을 시키지 않는다. 시키는 것은 **선택**(조문 문장 고르기)뿐이다. 판단은 사실 대조 규칙 또는 라벨로 학습·검증한 판별기가 한다.
2. 질문만 보고 가르는 신호는 더 쓰지 않는다 (6종 실패). 가르는 단위는 (질문, 근거 문장) 쌍이다.
3. 신호는 채택 기준을 측정 전에 고정하고, 미달이면 폐기한다. "애매하면 통과"는 없다.
4. 거부는 막다른 길이 아니다. 후보 조항 원문을 항상 보여 준다 (환각 0 유지).

## 3. 구조

```
질문
 → M0 입력 규칙        악용·개인정보·기관 미지정·기관 비교            규칙 (v3 그대로)
 → 검색 (현행 hybrid_prefilter, 변경 없음)
 → M3 적용 대상 규칙    질문 대상(임원·퇴직자·지원자 등) vs 적용 범위 조항   규칙 (v3 그대로, 8/8)
 → M2 근거 선택         7B 가 조문 문장을 고름 → 0개면 14B 가 다시 고름   캐스케이드 (신규)
 → M1 원문 검증         문자열 대조 + 출처 재연결                       규칙 (v2 그대로)
 → M4 답변성 판별       (질문, 검증된 문장) 쌍 → 답함/안 함              학습 판별기 (신규, 실험)
 → M5 응답 조립         원문 + 고정 문구 + 어긋남 표시, 최종 검사        규칙 (신규 항목 추가)
```

### M1 원문 검증 (유지)
`v2/guard.py` 의 검증·조립·최종 검사. 환각 0 의 근거. 바꾸지 않는다.

### M2 근거 선택 캐스케이드 (신규)
- 7B 가 인용 0개를 내면 같은 입력을 14B(`q14-q4`)에 넘긴다. 14B 도 0개면 거부.
- 근거: 7B 오거부 20건 전부 원시 인용 0개(검증 전 단계에서 비어 있음), 그중 14B 답변 16건.
- 실측(2026-10-12 캐시 재계산, **같은 적용 대상 규칙·같은 라벨**, 설계용 104): 7B+규칙(v3) 91% / 48%, 14B+규칙 79% / 17%, **캐스케이드 7B→14B+규칙 77% / 10%**, 14B 호출 68/104. 이전 판에 적었던 68%(v2 두 모델 합집합, 규칙 없음)는 조건이 섞인 수치라 폐기한다.
- 비용: 14B 는 8GB GPU 에서 1건 11초. 7B 가 거부하는 65%에만 걸린다. 응답 지연 상한은 5절.
- 부작용(알고 들어감): 거부율이 91% → 77% 로 떨어진다. 이 14%p 는 **14B 가 새는 것**이고, M4 가 이것을 다시 잡아야 v4 가 곡선을 벗어난다. M4 가 실패하면 M2 는 넣지 않는다 (7절).
- 부실험 M2' 문장 번호 선택: 조문을 항·호 단위로 번호를 매겨 보여 주고 7B 가 **번호만** 고르게 한다(글자 그대로 복사 부담 제거). 검증은 번호 존재 확인이므로 환각 0 유지. 채택 기준: 선택용 R 오거부 7B 단독 대비 8건 이상 감소 **그리고** 새는 것 2건 이하 증가. 14B 가 같은 형식으로 답했으므로 형식이 원인일 가능성은 낮지만, 7B 56회 호출(약 5분)이라 잰다.

### M3 적용 대상 규칙 (유지, 결함 1건 수정)
v3 G2 의 대상 명사 목록·적용 범위 조항 대조. 외부 검토(2026-10-12)에서 결함이 확인됐다: 적용 범위 조항에 "임원에게는 적용하지 않는다"처럼 **부정**이 있어도 "적용"이라는 글자만 보고 포함으로 읽었다. 부정·제외 표현을 먼저 보도록 고치고 테스트 3건을 추가했다(`v2/guard.py`, `test_guard_v3.py`, 39개 통과). 설계용 결과는 바뀌지 않는다(가스안전공사 적용 범위 조항에 대상 명사가 없음). "8/8 정확"은 규칙이 안전하다는 뜻이 아니라 그 8건에서 맞았다는 뜻이고, 다른 기관 조항에서는 다시 확인한다.

### M4 답변성 판별기 (신규, 실험)
- 무엇: (질문, 검증된 인용 문장) 쌍을 입력으로 "이 문장이 질문에 답한다 / 관련만 있다"를 내는 cross-encoder. 기반 모델은 현행 재랭커 계열(bge-reranker-v2-m3 또는 base)을 우리 라벨로 미세조정.
- 왜 이것이 이전 실패와 다른가: 재랭커 점수는 **관련성**이고, 새는 사례는 전부 "관련은 있는데 답은 아닌" 조문이다. 관련성 모델이 못 가르는 것이 당연하다. 답변성 라벨로 학습한 신호는 아직 재 본 적이 없다.
- 순서: **라벨 품질 확인이 미세조정보다 먼저다.** 정답 조문에서 숫자가 든 문장을 고른다고 답 문장이 되지 않고, 정답으로 등록되지 않은 조문에도 답이 있을 수 있다(외부 검토 지적). 자동 생성 쌍을 학습에 바로 넣지 않는다.
  - 4-a. 사람 검수 쌍 200개: 기존 세트(matrix·kgs_faq·dev·employee·기관별 4종)에서 (질문, 조문 문장) 쌍을 뽑아 **전부** 사람이 "답함 / 관련만 / 무관"으로 라벨한다. 자동 선택은 후보 제시용이다.
  - 4-b. 이 200쌍에서 **미세조정 없이** 현행 재랭커 점수의 답함 vs 관련만 AUC 를 먼저 잰다. 이것이 0.80 미만이면 "관련성 ≠ 답변성"이 확인된 것이고, 미세조정으로 넘어간다. 0.80 이상이면 미세조정 없이 임계값만 잡는다.
  - 4-c. 미세조정은 200쌍으로 5겹 교차검증으로 판별력을 먼저 보고, 교차검증 AUC 하한 ≥ 0.75 일 때만 확대한다(negative 123·나머지 세트의 자동 쌍 추가, 추가분도 표본 검수).
  - 학습에 astra 200문항은 쓰지 않는다. 알려진 편향: 기존 세트는 자작 질문이라 말투가 astra 와 다르다. 채택 판정은 astra 선택용으로만 한다.
- 채택 기준 (측정 전 고정, v3 S2 와 같은 기준): 선택용 56 에서 R vs NA+OUT AUC 부트스트랩 하한 ≥ 0.80, **일상어·상황설명만 따로** ≥ 0.75. 임계값은 선택용에서 "R 오거부 ≤ 2건" 조건으로 고른다.
- 미달 시: 폐기. 그러면 v4 는 M0+M3+M1+M5 로 확정하고 M2 는 넣지 않는다.
- 비용: 학습 쌍 약 1,500개, base 모델 미세조정 8GB GPU 에서 수십 분. 추론은 쌍당 수십 ms.

### M5 응답 조립에 어긋남 표시 (신규, 판단 불필요)
- 모든 답변에 조문 제목·적용 범위 조항 한 줄을 붙이고, **질문의 명사 중 인용 문장과 조문 제목 어디에도 없는 것**을 "규정 문장에 없는 항목: 가족, 지원" 식으로 적는다. 형태소 분석 없이 코퍼스 용어집(`L2/glossary.jsonl`)과 단순 어절 대조로 한다.
- 근거: H2 를 자동으로 다 못 잡는다는 것이 v1~v3 의 결론이다. 남는 것은 사용자가 판단할 수 있게 **어긋남을 보이는 것**이다. 단, 문자열 부재는 정확히 계산해도 "의미상 어긋남"은 아니다. 질문의 "월급"이 조문에서는 "보수"일 수 있다(외부 검토 지적). 그래서 (1) 용어집·동의어 자료(`L2/synonyms_seed.jsonl`)로 치환한 뒤 대조하고, (2) 문구를 "규정 문장에 같은 단어가 없는 항목"으로 써서 불일치를 단정하지 않는다.
- 측정: 사람 검수. 새는 답변 15건에 "표시를 보고 이 조문이 질문에 안 맞는다는 것을 알 수 있는가"(목표 12건 이상) **그리고** R 답변 15건에 "맞는 답인데 표시가 틀렸다고 오해하게 하는가"(**오경고율**, 목표 3건 이하). 오경고율이 목표를 넘으면 표시를 끈다.

### 하지 않는 것
- 질문만 보는 분류기(키워드·LLM·임베딩) 일체. 재랭커 점수 임계값.
- 검색 개선(W 15건은 가드레일 범위 밖). 재랭커 교체.
- 72B API 추출기: HF 크레딧 소진(402)으로 쓸 수 없다. 로컬 7B·14B 로 한정.

## 4. 데이터

- 설계용 104(선택용 56 / 점검용 48, `v2/split2.json`)와 봉인용 96 은 그대로. 봉인용은 열지 않는다.
- **NA 재검수는 설계용 27건만** (측정 전): 사유 열 추가 — 규정에 없음 / 라벨 오류(실제 답 있음) / 대상 밖 / 상황 애매. 라벨 오류는 R 로 바꾸고 변경 기록에 남긴다. **봉인용 96 의 NA 는 설계자가 보지 않는다.** 봉인용 라벨 오류는 개봉 후 결과 보고에서 "라벨 오류 의심"으로 따로 세고, 수정은 독립 검수자가 있을 때만 한다(이전 판의 "봉인용 NA 는 질문·라벨만 본다"는 봉인 위반이라 삭제).
- 점검용 48 은 v3 에서 이미 결과를 봤으므로 **독립 검증이 아니다.** 역할은 "선택용과 방향이 같은가"의 중간 확인뿐이고, 독립 평가는 봉인용 96 한 번이다.
- 말투 교란 주의: OUT 40건 중 30건이 전문용어 말투, R 82건 중 34건이 일상어다. 어떤 신호든 "말투"를 배워서 OUT 을 맞출 수 있으므로 **모든 채택 판정은 말투별 층화 수치를 함께 본다** (M4 기준에 명시).
- 새 문항은 만들지 않는다 (v3 와 같은 문항으로 비교).

| 거부율 | OUT+NA 중 거부 | ≥ 90% | v3 91% 유지가 하한 |
| 오거부율 | R 중 거부 | ≤ 15% | 95% 구간 상한 함께 보고 |
| 환각 | 조문에 없는 문장 | 0건 | 1건이면 하네스 결함, 전부 무효 |
| 곡선 이탈 | 위 두 지표 동시 달성 | 필수 | 7B(91/48)·14B(70/17)·합집합(68/10) 어느 점도 못 한 것 |
| 어긋남 표시 유효율 | M5 사람 검수 | 새는 답변 15건 중 12 이상 | |
| 응답 지연 | 1건 평균 | ≤ 10초 | 14B 호출 비율 × 11초 |

이전 목표(95% / 0%)에 대해: R 42건에서 0건 관측이어도 구간 상한 약 8% 라 0% 는 확인 자체가 불가능하다. 95%/0% 를 유지하려면 "미달"만 반복 기록하게 되므로, v4 는 **측정 가능한 목표**로 바꿔 제안한다. 확정은 사용자가 한다. 바꾸지 않겠다면 목표는 그대로 두고 결과를 미달로 기록한다.

## 7. 중단 조건

- 4단계 M4 미달 → M2 를 넣지 않는다 (14B 가 새는 것을 막을 수단이 없으므로). v4 = M0+M3+M1+M5 로 확정하고, "거부율은 v3 와 같고 오거부는 못 줄였다"로 기록. M2' 가 채택됐으면 그것만 넣는다.
- 7단계 점검용에서 선택용과 결론 방향이 다름 → 봉인용 열지 않고 원인 기록.
- 봉인용 환각 1건 이상 → 전부 무효.
- NA 재검수에서 라벨 오류가 10건 이상 → v3 수치와 비교 불가. v3 수치를 새 라벨로 다시 계산(캐시로 가능)한 뒤 진행.

## 8. 알려진 약점

1. M4 의 학습 데이터가 자작 질문이라 astra 말투와 다르다. 분포 차이로 실패할 수 있고, 그 경우 "답변성 라벨 부족"이 결론이 된다. 라벨 추가(사람 시간)는 이 계획 밖이다.
2. 설계용 R 42·OUT 20·NA 27 은 작다. 채택 기준의 구간이 넓어 "채택"이 운일 수 있다. 봉인용 96 이 마지막 방어선이고, 그 뒤는 없다.
3. M5 는 피해를 줄이지 자동 거부율을 올리지 않는다. 지표상 효과가 사람 검수에만 나타난다.
4. 14B 캐스케이드는 데모 PC 에서만 가능하다. 배포(HF Space, CPU)는 7B 조차 없어 "검색 근거만 표시"로 떨어진다. 배포 효과는 M3·M5 뿐이고, 6절 10단계에서 따로 잰다. 로컬 실험 수치를 배포 효과로 적지 않는다.
5. 실행 순서 1단계는 설계용 NA 27건 재검수로 바뀌었다(봉인 유지). 봉인용 라벨 오류는 개봉 전에는 알 수 없다.

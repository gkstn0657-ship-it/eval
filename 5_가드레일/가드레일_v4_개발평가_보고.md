- **부분 답변 표시의 출처**: 현재 `PARTIAL` 은 추출기의 `fully_answered=false` 자기 보고로 정해진다. v2 평가에서 이 신호는 변별력이 없다고 기록돼 있다(`가드레일_v2_결과.md`). 따라서 R 중 부분 답변 11/22건은 "모델이 스스로 일부라고 한 것"이지 실제 일부인지는 사람 검수에서 확인해야 한다. M4 가 들어오면 이 자리를 M4 라벨이 대신한다. 부분 답변 문구 자체는 사실 주장이 없다("확인되지 않은 부분은 확인하지 못했다").
- 캐스케이드 수치는 v2 캐시의 14B 출력을 재조합한 것이다. 14B 호출 조건(원시 인용 0개 또는 검증 전부 탈락, 1회)은 `guard_v4.py` 에 구현돼 있고 테스트로 확인했다. 실측 지연은 M4·사람 검수 결과를 본 뒤 `measure_latency.py` 로 잰다(콜드/웜 분리).

## 7. 실패 분석 (관측과 추정 분리)

관측:
- B 의 R 오거절 20건은 전부 7B 원시 인용 0개(v2 와 동일). 그중 14B 는 16건에 인용을 냈다(캐시).
- NA·OUT 에서 B 가 답한 4건, D 가 답한 11건은 전부 실제 원문 인용이다(원문 불일치 0). 즉 새는 것은 "엉뚱한 실제 조문"이다.
- 적용 대상 규칙이 발동한 8건은 가스안전공사 적용 범위 조항에 대상 명사가 없어 전부 미확인이다. 배제 확인·포함 확인은 이 세트에서 0건이라 규칙의 배제 판정 정확도는 측정되지 않았다.
- 코드 검사 탈락 0건.

추정(검증 안 됨):
- 7B 인용 0개는 추출기의 보수성으로 보이지만, 프롬프트 형식(글자 그대로 복사) 부담일 가능성은 배제하지 못했다(문장 번호 선택 실험은 이번 범위에서 하지 않음).
- 엉뚱한 실제 조문은 질문 단위 신호로 못 가른다는 것이 v1~v3 의 결론이고, 그래서 M4(조문 단위 답변성)를 두었다. M4 가 실패하면 D 는 확대하지 않는다.

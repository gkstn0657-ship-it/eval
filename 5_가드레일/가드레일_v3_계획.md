# 가드레일 v3 계획 (2026-10-07, 측정 전 고정)

v2 설계용 결과(`가드레일_v2_결과.md`)와 외부 검토를 반영한 최종 계획. 원문 대조 하네스(`v2/guard.py`)는 유지하고, 그 앞에 판정 단계를 분리해 붙인다.

## 0. 유지하는 것과 바꾸는 것

| 유지 | 바꾸는 것 |
|---|---|
| 원문 대조 검증, 템플릿 조립, 최종 검사 (환각 0 보장) | 범위 판정·적용 대상 판정을 추출과 분리해 **별도 단계**로 둔다 |
| 봉인용 96문항 봉인 유지 | "애매하면 통과"를 없앤다. 애매는 **안내 거부 + 후보 조항** |
| 목표 95% / 0% / 0건 (변경 불가) | 결과는 "달성/미달"과 함께 **신뢰구간 상한**으로 보고한다 |

## 1. 구조

```
질문
 → G0 입력 규칙   악용·개인정보·기관 미지정·기관 비교        규칙 (현행)
 → G1 범위 판정   인사규정 / 다른 규정 / 무관                 조문을 보지 않고 질문만. 신호는 2절에서 채택된 것만
 → 검색 (현행)
 → G2 적용 대상   질문 대상(임원·비정규직·외부인 등)이 적용 대상인가   대상 명사 규칙 + 적용 범위 조항 대조
 → G3 근거 추출   조문 문장 글자 그대로 복사                  7B (G1·G2 채택 시에만 완화 프롬프트)
 → G4 원문 검증   문자열 대조 + 출처 재연결                   규칙 (현행)
 → G5 응답 조립   원문 + 고정 문구, 최종 검사                 규칙 (현행)
```

| 단계 | 거부 판정 시 | 애매·실패 시 |
|---|---|---|
| G1 | "인사규정이 아니라 ○○규정 소관" 안내 거부. 소관 규정명은 위임 규정 목록에 있는 것만 쓴다 | **안내 거부** + 가장 가까운 조항 후보 3개. 통과시키지 않는다 |
| G2 | "이 규정은 직원에게 적용되며 ○○는 별도 규정" 안내 거부 | 적용 범위 조항을 못 찾으면 **대상 명사 규칙만으로** 안내 거부 |
| G3·G4 | 인용 0개 또는 검증 실패 → "찾지 못함" + 후보 조항 3개 (현행) | |
| 모든 거부 | 응답에 "그래도 관련 조문 원문 보기" 선택지를 둔다. 원문만 보여 주므로 환각 0은 유지 | |

## 2. 신호 변별력 측정 (G1, 기존 설계용 104문항으로 지금 바로)

세 집단으로 본다: 범위 밖(OUT 20), 정답 없음(NA 27), 답해야 함(R 42). 답 있는데 검색 실패(W 15)는 별도 집계.

| 후보 신호 | 입력 | 출력 | 채택 기준 (측정 전 고정) |
|---|---|---|---|
| S1 7B 범위 분류, 목차·위임 규정 목록 제시 | 질문 + 기관의 장 제목 목록 + 위임 규정명 목록 | 인사규정/다른규정/무관 + 확신도 0~1 | OUT 재현율 ≥ 0.9 **그리고** R 오분류 ≤ 1건(42건 기준). 둘 다 만족하면 거부에 사용. 하나만 만족하면 안내 문구에만 사용. 둘 다 미달이면 폐기 |
| S1' 7B 범위 분류, 목록 없이 질문만 | 질문만 | 같음 | S1 과 비교해 "목록 제시"가 효과인지 분리. 채택 기준 같음 |
| S2 임베딩 유사도 차 | 질문 벡터 vs 장 제목 벡터 평균, vs 위임 규정명 벡터 평균 | 연속값 | AUC(OUT vs R) 부트스트랩 하한 ≥ 0.80. **일상어 질문만 따로** 센 AUC 도 ≥ 0.75. 미달이면 폐기 |
| G2 대상 규칙 | 대상 명사 목록 | 대상 밖/안 | 설계용에 대상 밖 문항이 4건뿐이라 지금은 채택 판정 불가. 보강 데이터(4절)에서 오분류 ≤ 1건이면 채택 |

- S1·S1' 은 재랭커 점수(AUC 0.60)와 LLM scope 판정(변별력 없음)이 실패한 것과 같은 종류다. 다른 점은 "조문을 안 보여 줌"과 "목록을 보여 줌" 둘뿐이고, S1' 을 함께 재서 어느 것이 작동하는지 분리한다.
- 채택 신호가 하나도 없으면: **가드레일은 G0 + G3~G5 + 안내 문구로 확정하고 종료**한다. 목표 미달로 기록한다.

## 3. 설계용 데이터의 사용 규칙 (선택 편향 방지)

- 기존 설계용 104문항을 **선택용 52 / 점검용 52** 로 다시 나눈다(라벨·말투 층화, seed 고정). 봉인용 96은 손대지 않는다.
- 신호 선택(S1/S1'/S2), 프롬프트 후보 선택, 규칙 작성은 선택용 52로만 한다.
- 점검용 52는 전체 구성을 조립한 뒤 **한 번** 본다. 여기서 선택용 결과와 방향이 다르면 봉인용을 열지 않고 멈춘다.
- G3 완화 프롬프트는 후보 2개를 측정 전에 고정하고, 선택용에서 고른다. 완화는 G1 또는 G2 가 채택됐을 때만 적용한다.

## 4. 평가 데이터 보강 (G2 판정과 봉인 확인용)

| 유형 | 건수 | 작성 방법 |
|---|---|---|
| 범위 밖: 복무(근무시간·연차) | 20 | 외부 AI 생성 시 **기존 200건과 다른 생성기** 사용. 말투 비율(일상어 35%, 오타 20%, 상황설명 15%, 전문용어 15%, 기타)을 기존과 맞춘다 |
| 범위 밖: 여비·출장, 교육, 규정 무관, 법률 해석 | 10·10·20·10 | 같음 |
| 적용 대상 밖: 임원, 비정규직·파견, 퇴직자·지원자 | 10·10·10 | 같음 |
| 악용·개인정보 입력 | 10·10 | 사람 작성 |
| 기존 NA 51건 | 재검수 | 라벨에 사유 열 추가(규정에 없음 / 상황 애매 / 검색 실패) |

- 새 문항은 선택용 결과를 보지 않은 상태에서 만든다. 기존 200건과 정답 조문 ID·문장 유사도로 중복 검사 후 제거.
- 새 문항 약 120건은 **추가 설계용 60 / 추가 봉인용 60** 으로 나눈다. 기존 봉인용 96 + 추가 봉인용 60 = 156건이 최종 확인 세트.
- 사람 시간은 작성·검수·재검수를 분리해 기록한다(검수자 2인 가능 여부 확인 필요).

## 5. 지표와 보고 방식 (측정 전 고정)

| 지표 | 정의 | 목표 | 보고 |
|---|---|---|---|
| 거부율 | OUT+NA 중 안내 거부·거부 비율 | ≥ 95% | 값 + 95% 구간 |
| 오거부율 | R 중 거부·되묻기 비율. G0 기관 비교 거부는 **별도 집계**(라벨 확인 필요) | 0% | 값 + 구간 상한 (0건이어도 상한 보고) |
| 환각 | 응답 중 조문에 없는 문장 포함 | 0건 | 건수 |
| 소관 안내 정확도 | G1 거부 중 소관 규정명이 맞은 비율 | ≥ 70% | 사람 검수 |
| W 후보 적중 | 검색 실패 문항 거부 시 후보 3개에 정답 조항 포함 비율 | 참고 | |
| 응답 지연 | G1 추가 후 1건 평균 | 현행 +2초 이내 | |

추출 모델은 7B 고정(14B 는 지연 3.5배). 14B 는 참고로만 같은 입력에 돌린다.

## 6. 실행 순서

| 순서 | 작업 | 데이터 | 비용 |
|---|---|---|---|
| 1 | 설계용 104 → 선택용 52 / 점검용 52 분할 | 기존 | 10분 |
| 2 | S1·S1'·S2 변별력 측정 | 선택용 52 | 7B 104회 호출 약 10분, 임베딩 1분 |
| 3 (병행) | 데이터 보강 120건 작성·검수, NA 재검수 | 신규 | 사람 1~2일 (추정) |
| 4 | 채택 신호로 G1 구현, G2 규칙 작성 | 선택용 52 + 추가 설계용 60 | 3시간 |
| 5 | G3 완화 후보 2개 비교 (G1 또는 G2 채택 시에만) | 선택용 52 | 7B 약 10분 |
| 6 | 전체 구성 조립, 점검용 52 1회 확인. 방향 불일치면 중단 | 점검용 52 | 30분 |
| 7 | 봉인용 156 1회 개봉 | 봉인용 | 7B 약 20분 |
| 8 | 결과 문서, 정책 변경 기록 | | 1시간 |

2단계는 3단계를 기다리지 않고 지금 시작한다.

## 7. 중단 조건

- 2단계에서 채택 신호 0개 → 4~7 실행하지 않고 "원문 검증 + 안내 문구" 구성으로 확정, 목표 미달 기록.
- 6단계 점검용에서 선택용과 결론 방향이 다름 → 봉인용 개봉 금지, 원인 기록 후 재설계.
- 봉인용에서 환각 1건 이상 → 하네스 결함이므로 모든 결과 무효, 수정 후 재측정(단, 봉인용은 이미 열렸으므로 추가 봉인용으로만 확인).

## 8. 이 계획의 알려진 약점

1. G1 의 LLM 신호(S1)가 이전 실패와 같은 종류라 채택되지 않을 가능성이 크다. 그 경우 범위 판정 자동화 수단이 없고, 가드레일은 "환각 0 + 안내"에서 멈춘다.
2. 오거부율 0% 는 봉인용 156건으로도 확인할 수 없다(0건이어도 구간 상한 약 2%). 목표 달성은 "0건 관측"으로만 보고한다.
3. 데이터 보강이 사람 시간에 묶여 있고, 다른 생성기로 만들어도 실제 사용자 분포와는 다르다.

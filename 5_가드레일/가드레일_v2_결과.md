# 가드레일 v2 설계용 평가 결과 (2026-10-07)

정책: `가드레일_정책_v2.md`. 하네스: `v2/guard.py`. 데이터: 외부 AI 작성 질문 200건 중 설계용 104문항(사람 라벨 R 42 / W 15 / NA 27 / OUT 20). 봉인용 96문항은 열지 않았다.
수치 정본: `v2/results/summary_dev_*.json`, `rows_dev_*.json`.

## 결론

**근거 없는 답변 0건은 두 구성 모두에서 지켜졌다.** 답변 본문이 조문 원문과 고정 문구로만 조립되는 구조가 설계대로 동작했다(답변 87건 전부 최종 검사 통과).
**거절 재현율 95%·오거절 0% 목표는 어떤 구성도 못 미쳤다.** 추출기 모델에 따라 "많이 거절(7B)" 과 "많이 답함(14B)" 사이에서 자리만 바뀌고, 둘을 합쳐도 같은 곡선 위에 있다.

| 구성 (설계용 104) | 거절 재현율 (목표 95%) | 오거절률 (목표 0%) | 근거 없는 답변 | 답변 수 | 응답 시간 |
|---|---|---|---|---|---|
| 7B 추출기 | 83% | 48% | 0 | 32 | 3.1초 |
| 14B 추출기 | 70% | 17% | 0 | 55 | 11.0초 |

### LLM 의 자기 판정 신호는 쓸 수 없었다

추출 JSON 의 `scope`(인사규정/다른규정/무관)와 `fully_answered` 를 결정 규칙에 넣어 봤다(새 호출 없이 캐시로 계산).

| 규칙 | 7B | 14B |
|---|---|---|
| 검증 인용 있음 (현재) | 83% / 48% | 70% / 17% |
| + scope 가 인사규정일 때만 | 85% / 48% | 70% / 17% |
| + fully_answered 일 때만 | 89% / 74% | 87% / 52% |

14B 는 범위 밖 질문 20건 중 9건에 "인사규정"이라고 적었고, `fully_answered` 는 거절 재현율을 올리는 만큼 오거절을 더 올린다. 어느 신호도 "거절할 질문"과 "답할 질문"을 가르지 못한다. 폐기한 1차 가드레일에서 재랭커 점수가 가르지 못했던 것과 같은 결론이다.

## 해석

- 근거 검증(문자열 대조)은 "조문에 없는 말"을 완벽히 막지만, "조문에 있는 말을 엉뚱한 질문에 붙이는 것"은 막지 못한다. 범위 밖·적용 대상 밖 질문은 **관련 조문이 실제로 있기 때문에** 원문 인용만으로는 거절 근거가 안 된다.
- 현재 부품(7B·14B 로컬 모델)으로 95%/0% 에 도달할 방법은 측정 범위 안에 없었다. 둘 중 하나를 고르면 "오거절 17%·새는 30%" 또는 "오거절 48%·새는 17%" 다.

## 다음 단계 후보 (사용자 판단 필요)

1. **적용 대상 판정 항목 추가**: 추출 JSON 에 "질문 대상(임원·외부인 등)이 이 규정의 적용 대상인가"를 넣는다. 새는 것 중 임원 질문 4건을 노린다. 새 LLM 호출 필요.
2. **범위 밖 분류를 별도 단계로**: 질문 주제를 위임 규정 목록·규정 목차와 대조하는 작은 분류기를 따로 두고 분리력을 먼저 잰다. 키워드 단독은 금지(폐기 사유).
3. **7B 프롬프트 완화**: "질문 일부에라도 답이 되면 인용"으로 바꿔 인용 0개 18건을 줄인다. 오거절은 줄고 새는 것은 늘 가능성이 크다.
4. **목표치 재검토**: 95%/0% 는 현재 부품으로 미달. 목표를 낮추지 않고 "미달"로 기록하는 것이 지금 상태다.

# 가드레일 구축 계획 (2026-10-05)

전제: 검색 파이프라인(hybrid_prefilter)은 nDCG@5 0.89~0.99 수준이고, 거절 로직은 전혀 없다(음성 세트 123문항 거절률 0%). 남은 오류를 없애는 것이 아니라, 틀린 답이 사용자에게 나가는 횟수를 줄이는 것이 목표다.

## 측정된 출발점

| 세트 | 성격 | 재랭커 top1 점수 |
|---|---|---|
| 음성 123 (정답 없음) | 연차·성과급·여비·퇴직금·육아시간 | 최대 0.070 |
| 매트릭스 111 (정답 있음, 정형 질문) | 정년·명예퇴직·징계시효·수습 | 최소 0.730 |
| 가스FAQ 38 (정답 있음, 자연어 질문) | 11개 유형 | 중앙값 0.390, 최소 0.001 |

임계값별 효과(현재 파이프라인, 실측):

| 임계값 | 음성 거절률 | 오거절: 정형 | 오거절: 자연어 FAQ |
|---|---|---|---|
| 0.05 | 99% | 0% | 13% |
| 0.07 | 100% | 0% | 18% |
| 0.20 | 100% | 0% | 24% |
| 0.30 | 100% | 0% | 45% |

→ 단일 임계값 하나로는 자연어 질문의 13~18%를 맞는 답인데도 거절한다. 임계값은 1차 필터로만 쓰고, 저점수 구간은 2차 판정으로 넘긴다.

## 구성 (6단계)

```
질문 → [G1 입력 분류] → [검색] → [G2 검색 게이트] → [생성] → [G3 출력 검증] → [G4 화면·면책] → [G5 운영 환류]
```

### G0. 정책 정의 (코드 이전, 현업 기준 1순위)
- 답하지 않는 주제 목록: 보수·수당·복지·여비·연금(별도 규정 소관), 개인 사안 판단(내 징계가 정당한가).
- 고위험 주제 목록: 징계·해고·직권면직·성비위. 답변 대신 조문 원문 + 담당부서 안내.
- 면책 문구와 "담당자 확인" 안내 문안 확정.
- 산출물: `정책.md` 1장. 성공 기준: 주제별 처리 방식(답변/원문만/거절/연결)이 표로 정해져 있을 것.

### G1. 입력 가드레일: 질문 분류
- 범위 밖 판정: 1단계 키워드 규칙(연차·성과급·여비·퇴직금·연금·수당·복지), 2단계 소형 분류기. 학습 재료는 이미 있다: 범위 밖 FAQ 94건 + 음성 세트 123건(양성), 가스FAQ·매트릭스(음성).
- 고위험 판정: 키워드 규칙으로 시작(징계·해고·면직·성희롱). 오탐이 나도 "원문만 표시"라 피해가 없다.
- 기관 비교 질문 감지: 질문에 기관명 2개 이상이면 "기관별로 따로 질문" 안내. 현재 Q6 nDCG 0.20의 임시 처리.
- 측정: 범위 밖 재현율(음성 세트), 범위 안 오탐률(가스FAQ·매트릭스·기존 242문항).
- 성공 기준: 범위 밖 재현율 ≥ 95%, 범위 안 오탐률 ≤ 3%.

### G2. 검색 신뢰도 게이트 (2단계)
- 1단계: top1 재랭커 점수 ≥ 0.30 → 통과. < 0.05 → 거절 후보.
- 2단계(0.05~0.30 회색 구간 + 거절 후보): 상위 3개 조문에 대해 LLM 관련성 판정("이 조문이 질문에 답하는가" 예/아니오). 하나라도 예 → 통과, 전부 아니오 → 거절 "관련 조항을 찾지 못했습니다".
- 거절 시 출력: 검색된 조문 제목 3개를 "혹시 이 조항인가요"로 제시(오거절 피해 완화).
- 비용: 회색 구간은 자연어 질문의 약 절반이므로 전체 질문의 20~30%에서 LLM 호출 1회 추가.
- 측정: 음성 거절률, 양성 오거절률(유형별), 2단계 호출 비율.
- 성공 기준: 음성 거절률 ≥ 95%, 자연어 양성 오거절률 ≤ 5%(현재 단일 임계값 18%에서 개선).

### G3. 출력 가드레일: 답변 검증
- 인용 강제: 답변 문장마다 조문 번호를 붙이게 하고, 전달하지 않은 조문 번호가 나오면 폐기.
- 숫자 대조: 답변에 등장하는 숫자+단위(60세, 3년, 10일, 10분의 1)가 근거 조문 본문에 있는지 정규식으로 확인. 하나라도 없으면 답변 대신 조문 원문만 표시.
- "없음" 일관성: G2가 거절했는데 생성이 답을 만들면 차단.
- 측정: HITL 창에서 사람이 판정한 환각 건수 대비 자동 차단 비율. 지금 HITL 로그가 3건뿐이라 먼저 50건 이상 쌓아야 한다.
- 성공 기준: 사람이 잡은 환각 중 자동 차단 ≥ 70%.

### G4. 화면과 면책
- 근거 조문 펼쳐보기(조문 번호·원문·개정일) 기본 표시. 지금 HITL 화면에 이미 있음.
- 면책 문구 고정 노출, 도움됨/오류신고 버튼.
- 고위험 주제는 답변 영역을 비우고 원문 + 담당부서 안내만.
- 성공 기준: 모든 응답에 근거 또는 거절 사유가 붙어 있을 것(근거 없는 답변 0건).

### G5. 운영 환류
- 로그: 질문·기관·검색 상위5·점수·게이트 판정·답변·신고 저장(hitl_questions.jsonl 확장).
- 신고 건 → 사람 판정 → 평가셋 추가(출처 `report`) → 월 1회 재측정.
- 규정 개정 감지 → 코퍼스 갱신 → 전 세트 재실행.

## 순서와 산출물

1. G0 정책 문서 → 2. G2 1단계 임계값 + 측정(코드 수십 줄, 바로 가능) → 3. G1 키워드 규칙 → 4. G2 2단계 LLM 판정 → 5. G3 숫자 대조 → 6. G4 화면 → 7. G5 로그·환류.

2단계까지는 지금 결과만으로 하루 안에 끝난다. 4단계부터 LLM 호출 비용과 HITL 데이터가 필요하다.

## 범위 밖
- 기관 간 비교 검색(Q6) 자체의 개선은 검색 파이프라인 과제. 여기서는 G1에서 감지해 안내만 한다.
- 재랭커 교체·파인튜닝은 다루지 않는다.

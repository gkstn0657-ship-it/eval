# 가드레일 v2 하네스

정책: `../가드레일_정책_v2.md`. 기존 가드레일(`../guardrails.py`)은 폐기.

| 파일 | 역할 |
|---|---|
| `guard.py` | 하네스. 입력 규칙 → LLM 근거 추출(JSON) → 원문 대조 검증 → 처리 결정 → 템플릿 조립 → 최종 검사 |
| `test_guard.py` | 단위 테스트 23개. 가짜 LLM 으로 정책 경로를 하나씩 검사 (`python -m unittest test_guard -v`) |
| `eval_guard.py` | 외부 질문 200건(사람 라벨)으로 지표 측정. 설계용 104 / 봉인용 96 (`split.json`, 고정) |

보장되는 것: 답변 본문은 조문 원문을 문자 그대로 옮긴 문장과 고정 문구로만 만들어진다. 조문에 없는 문장은 나갈 수 없다(근거 없는 답변 0건).
측정해야 하는 것: 거절 재현율(목표 95% 이상), 오거절률(목표 0%). LLM 이 답이 되는 문장을 얼마나 정확히 고르는지에 달려 있다.

봉인셋은 `--sealed --confirm-open` 으로만 열리고, 열면 `sealed_open.log` 에 기록이 남는다.

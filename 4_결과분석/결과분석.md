# 결과 분석 (dev 44문항, 2026-10-01)

대시보드: `dashboard.html` (`build_dashboard.py` + `narrative.json` 으로 생성). 수치 정본: `3_성능테스트/results/summary.json`, `per_query.json`.

## 결론

1. **검색 구조가 결과를 결정한다.** 하이브리드+CE nDCG@5 0.77, Vanilla 0.17 (L2 최신판). 차이 +0.59, 95% CI [+0.44, +0.72]. 단독 축(dense 0.31, BM25 0.21)과 비교해도 하이브리드가 +0.46, +0.56 으로 유의하다.
2. **정제 강도는 유의한 차이를 만들지 않았다.** 하이브리드 L0 0.73 → L1 0.75 → L2 0.77, CI 가 0을 포함. Vanilla 는 오히려 L2 가 가장 낮다(0.17).
3. **개정판 전체 적재는 손해다.** 하이브리드 B 0.66 vs A 0.77, Δ −0.10, CI [−0.20, −0.02]. 같은 조문의 다른 개정판을 정답으로 인정했는데도 떨어졌으므로, 다른 조문의 구판이 상위를 차지한 것이다.
4. **범위 외 질의는 아무도 거절하지 못했다.** Vanilla 1위 유사도 0.53~0.69 로 임계값 0.5 초과. 하이브리드는 거절 장치 없음.

## 유형별 (하이브리드, L2 최신판, Recall@5)

조항 조회·요건·수치·절차·별표·삭제 조항·일상어·기관 비교 100%. 용어 정의 50%, 개정 이력 50%.

- 용어 정의 실패 2건: 정의 조항(제2조·제3조)이 길어 1,200자 기준 고정 분할되었고, 질의가 다른 조문으로 끌려갔다. 호(1. 2.) 경계 분할이 필요하다.
- 개정 이력 실패 2건: L2 가 개정 표기를 본문에서 떼어 메타데이터로 옮긴 결과(R-04), "2024년 개정" 질의가 본문에서 매칭되지 않았다. L0 에서는 같은 유형이 0.88 이었다. 분리한 표기를 검색 가능한 형태(메타데이터 필터 또는 접두어)로 되돌려야 한다.

## 격차 분해 (참고 측정 v4·v5, L2 최신판 nDCG@5)

| 구성 | 값 | 직전 대비 |
|---|---|---|
| Vanilla (ko-sbert) | 0.174 | |
| + 기관 필터 | 0.514 | **+0.34** (CI [+0.22, +0.47]) |
| Vanilla (bge-m3) + 기관 필터 | 0.638 | +0.12 (임베딩 교체) |
| + 재랭킹 (= 하이브리드 − BM25) | 0.726 | +0.09 (CI [+0.03, +0.15]) |
| + BM25 (= 하이브리드) | 0.766 | +0.04 (비유의) |

교차 검증(v6): 하이브리드에서 기관 필터만 빼면 0.766 → 0.457 (−0.31, CI [−0.43, −0.21]). Vanilla 에 더했을 때(+0.34)와 크기가 같다. 필터 없는 하이브리드(dense+BM25+CE)는 Vanilla(bge-m3) 대비 +0.15 에 그친다.

결론: 하이브리드와 Vanilla 의 격차 +0.59 중 절반 이상이 기관 필터다. 모델(임베딩·재랭커)보다 메타데이터 필터가 컸다. 이 코퍼스의 성질(20기관 × 같은 조항 구성) 때문이며, 단일 기관 규정이었다면 필터 몫은 0 에 가까웠을 것이다.

## 구성요소 제거 비교 (참고 측정 v4)

| L2 최신판, nDCG@5 | 값 |
|---|---|
| 하이브리드 + CE | 0.766 |
| 하이브리드 − BM25 (dense → 기관 필터 → CE) | 0.726 |
| Vanilla (bge-m3) | 0.305 |

- BM25 제거 효과 −0.04, 95% CI [−0.10, +0.00]. 유의하지 않다. L0 에서도 −0.055, 비유의.
- 기관 필터 + 재랭킹의 몫은 +0.42 (유의). Vanilla 와의 격차는 대부분 여기서 나온다.
- 유형별로 BM25 가 기여한 곳은 수치 확인(Q3 100%→75%)과 용어 정의(Q5 50%→25%) 뿐. 조항 번호 질의(Q1)는 BM25 없이도 100%.
- 해석: "키워드 축이 조번호를 잡는다"는 chat_rag 당시 가설은 이 코퍼스에서는 주된 메커니즘이 아니다. 기관 필터가 후보를 좁히면 재랭커가 조번호를 대조할 수 있다. 다음 측정에서 기관 필터 유무를 떼어 재야 한다.

## 부가: Vanilla 임베딩 교체 (참고 측정 v2)

기존 챗봇 RAG 의 임베딩을 하이브리드와 같은 bge-m3 로 맞추면 Recall@5 30% → 50%, nDCG@5 0.17 → 0.31. 하이브리드와의 차이 +0.46 은 남는다. 격차의 주원인은 임베딩이 아니라 키워드 축·재랭킹 구조의 부재다.

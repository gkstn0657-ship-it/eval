# 청킹 전략과 근거 (2026-10-06)

실험 상세: `청킹비교_결과.md`. 계획서: `3_성능테스트/1006_청킹비교_실험계획.md`.

## 청킹 전략

조 단위로 자른다. 인사규정은 조마다 제목이 있고 조 하나가 주제 하나를 다루므로 조각 하나가 곧 답 하나가 된다.

예외는 두 가지다.
- 1,200자가 넘는 긴 조는 항(①②) 경계에서 나누고, 조각마다 "제31조(정년)" 같은 조 제목을 붙인다.
- 용어 10여 개가 몰린 정의 조항은 호(1. 2.) 단위로 나눈다. 용어 정의 질문이 50% → 75% 로 올랐다.

## 실험 설계

- 검색 파이프라인(기관 사전 필터 + 하이브리드 + 재랭커)을 고정하고 청킹만 바꿨다.
- 292개 기관 코퍼스, 평가 4세트 229문항. 비교 조건과 판정 기준은 측정 전에 정했다.

| 방식 | nDCG@5 | 조 단위 대비 |
|---|---|---|
| 조 단위 (현재) | 0.937 | |
| 항 단위 | 0.929 | 차이 없음 |
| 의미 단위 | 0.653 | −0.28 유의 |
| 고정 1,200자 | 0.323 | −0.62 유의 |

## 결과 해석

성능을 가른 것은 조각 크기가 아니라 조 경계를 지켰느냐다.

- **조 단위·항 단위**: 둘 다 조 경계를 지켜 최상위 성능이 나왔다. 항 단위는 더 잘게 나눴을 뿐 다른 조와 섞이지 않고 조 제목도 남아 있다.
- **고정 길이·의미 단위**: 조 경계를 넘어 잘려 옆 조문과 섞였다. "제37조가 정답인데 제36조가 1위" 같은 오답이 났다.
- **항 단위를 쓰지 않은 이유**: 성능 이득 없이 조각 수만 1.9배로 늘었다. 일상어 질문에서는 항 하나로는 문맥이 부족해 몇 문항 떨어졌다.

## 결론이 흔들리지 않은 근거

측정 전에 정한 보조 분석 세 가지에서도 결론이 같았다.
- 조각에 든 조문을 모두 정답으로 인정한 채점(큰 조각에 유리)
- 한 유형에 쏠린 matrix 세트 제외
- 현재 방식에 유리할 수 있는 dev 세트 제외

## 한 줄 요약

문서가 이미 주제별로 나뉘어 있으면 그 구조를 따라 자르는 것이 가장 좋고, 범용 분할 방식과 비교한 측정으로 이를 확인했다.

## 면접용 답변

인사규정은 조 하나가 주제 하나라서 조 단위로 잘랐습니다. 같은 검색 파이프라인에서 청킹만 바꿔 229문항으로 비교했더니 고정 길이는 0.94 → 0.32, 의미 단위는 0.65 로 떨어졌습니다. 조 경계를 넘어 잘려 정답 옆 조문을 1위로 냈기 때문입니다. 항 단위는 조 경계를 지켜 성능이 같았지만 조각 수만 2배가 돼서 쓰지 않았습니다. 결국 조각 크기보다 문서 구조를 지키는 것이 핵심이었습니다.

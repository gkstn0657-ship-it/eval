# 2026-10-01 데이터셋 준비와 정제

진행 단계: 데이터셋 준비 → **데이터 전처리(파싱·정제)** → 파이프라인 설계(준비됨) → 성능 테스트 → 결과 분석 → 회고

## 1. 방향 결정

- 질문: 현업(클라이언트·부서)이 넘기는 문서 형태를 고려하면 파이프라인 투입 전 정제가 필요한가.
- 결론: 필요하다. 단, 정제를 측정 전에 끝내는 전처리로 두지 않고 측정 대상에 포함한다.
- 적용: 원본 보존, 규칙마다 실패 질의 명시, 정제 수준(L0/L1/L2)을 실험 변수로.
- 기록 방식: 커밋 메시지(결론 먼저, 명사형 불릿). PDF 진행기록은 폐기.

## 2. 기준 raw 데이터셋

- 결정: 공기업 인사규정 HWP 원본. ALIO(공공기관 경영정보 공개시스템) 내부규정에서 수집.
- 근거: 현업 형식(HWP)과 chat_rag 입력(txt·md·pdf)의 간극이 가장 큼. 조·항·호 구조로 조항 단위 청킹 검증 가능. 개정판 다수로 near-duplicate 방해 문서 확보.
- 수집 경로: 한국전력 사규 페이지는 다운로드 파라미터가 JS 암호화라 실패. ALIO 목록 API(`/occasional/findRuleList.json`, 분류 K1100, 검색어 "인사규정" 533건)와 다운로드 엔드포인트(`/download/rulefiledown.json?fileNo=`)로 전환.
- 대상: 시장형(A2001)·준시장형(A2002) 공기업 중 제목이 정확히 "인사규정"인 22기관.
- 결과: HWP 33파일(12기관, 기관별 최신 3개 개정판), PDF 8파일(HWP 미공시 8기관). 한전KPS·지역난방공사는 zip만 제공해 제외.
- 라이선스: ALIO 공개 자료. 재배포 전 공공누리 유형 확인 필요.

## 4. 질의 정의

- 실제 사용자 질의를 받을 수 없어 페르소나 5종(일반 직원, 인사 실무, 제도 개선, 감사·법무, 신규 입사자)으로 요구사항 추출.
- 질의 유형 Q1~Q10: 조항 조회, 요건 판단, 수치, 절차, 용어, 기관 비교, 개정 이력, 별표, 범위 외, 삭제 조항.
- 사용자 검토 반영: **Q11 일상어 질의** 추가. 신입사원이 규정 용어를 모르고 상황을 설명하는 유형("아기 낳으면 얼마나 쉴 수 있어?" → 출산전후휴가·육아휴직). 판정 기준: 질의 단어가 정답 조문에 0~1개만 포함.

결정

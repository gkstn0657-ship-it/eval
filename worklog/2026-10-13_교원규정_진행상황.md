## 막힌 것 — HF 쓰기 토큰

`python 6_배포/build_space_teacher.py --upload` 가 403 (저장된 HF 토큰이 읽기 전용). 집에서:

1. https://huggingface.co/settings/tokens 에서 **Write** 권한 토큰 생성
2. `hf auth login` (토큰 붙여넣기, git credential 은 n)
3. 아래 순서로 실행

```
# 이 PC 에 없는 것 두 개를 먼저 만든다 (둘 다 .gitignore 라 저장소에 없음)
#  (1) 포폴_정리/.env            : LAW_API_OC=<law.go.kr Open API 아이디>   (수집기 재실행 때만 필요)
#  (2) 임베딩 캐시 3_성능테스트/cache/bge-m3.npz 에 교원 청크가 있어야 조립이 된다 → smoke 를 한 번 돌리면 생긴다
cd 3_성능테스트 && PYTHONIOENCODING=utf-8 python smoke_teacher_corpus.py   # GPU 있으면 2~3분, CPU 면 10분+
cd ..
PYTHONIOENCODING=utf-8 python 6_배포/test_space_teacher_local.py          # 로컬 점검 (선택)
PYTHONIOENCODING=utf-8 python 6_배포/build_space_teacher.py --upload      # Space 생성 + 시크릿(RAG_KEY, HF_TOKEN) + 업로드
```

업로드가 끝나면 `6_배포/.rag_key` 에 호출 키가 생긴다. Space 주소: `https://runningturtle123-teacher-rules-rag.hf.space`
Space Settings 에서 하드웨어를 **CPU upgrade(유료, 상시)** 로 바꾸면 잠들지 않는다. `ANTHROPIC_API_KEY` 시크릿을 넣으면 근거 추출 LLM 이 Haiku 로 바뀐다(없으면 HF_TOKEN 의 Qwen 72B, 월 한도 있음).
